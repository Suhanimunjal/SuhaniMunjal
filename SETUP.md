# GitHub profile setup

1. Create or open the profile repository named exactly `Suhanimunjal` under the `Suhanimunjal` GitHub account.
2. Put `README.md`, the `assets/` folder, and `.github/workflows/snake.yml` into that repository.
3. Commit to the `main` branch.
4. Open **Actions → Generate contribution snake → Run workflow** once.
5. After the workflow publishes the `output` branch, the snake section in the README will start rendering.

The profile README intentionally avoids copying the resume. It uses the resume only as reference for the themes and projects represented.
